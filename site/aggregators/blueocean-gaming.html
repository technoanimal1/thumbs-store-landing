Why thumbnails matter for a BlueOcean Gaming catalogue

Aggregators like BlueOcean Gaming give an operator thousands of games from dozens of studios through a single integration — but artwork still arrives in each studio’s own style, sizes and quality. A lobby built on a BlueOcean Gaming feed needs one consistent set of thumbnails, in the sizes the UI expects, refreshed as new games are added. thumbs.store draws every game on one template so the lobby reads as one product, whichever studio a title comes from.

We cover 10,000+ games across 100+ studios today. For a BlueOcean Gaming integration, each game you receive is matched to its provider and title, and the matching thumbnail is returned — brand-accurate, in all four sizes, over API and CDN.

Game ID → thumbnail mapping

Your BlueOcean Gaming feed identifies each game by an aggregator game ID. We map that ID to the game’s provider and title, then serve the thumbnail for it. One call returns the whole set, each with a thumbnail_url:

GET /v1/games
x-api-key: YOUR_API_KEY

→ 200 OK  ·  JSON: your games grouped by provider,
  each with a thumbnail_url in four sizes.

# one game by provider + game slug
GET /v1/games/{provider-slug}/{game-slug}
