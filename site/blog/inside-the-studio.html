Inside the studio: build a lobby’s art without a design file.

Most lobby art dies in a handoff: ops needs a tile, design has a queue, and the game waits. The thumbs.store studio removes the handoff entirely — it is a thumbnail editor an ops team can drive, with the renderer doing the design work.

Open the studio and you are looking at your catalogue, not a blank canvas. The games you cover are already there, each one rendered through the house template. The job is no longer “make a thumbnail from scratch” — it is “pick a game and fine-tune the frame,” which is a job anyone on the team can do.

Pick a game, see it rendered

Select a title and the studio composites it live: background, key visual, logo and frame, assembled by the same template that draws every other tile in your lobby. There is no importing of source files, no layer wrangling — the provider’s assets are already in place, and the render updates as you work.

Tune the frame, not the pixels

Everything you adjust is a property of the template, not a brush stroke:

  • Treatment — show the provider’s logo, or set the title as type when the logo is weak or missing.
  • Accent — the colour that drives the light band and glow behind the art.
  • Bands, glows and bloom — the lighting that makes the frame look lit instead of pasted.
  • Provider tab — the studio label that keeps the grid readable at a glance.

Because these are template parameters, a change you like can become the default for a whole provider or the whole lobby — you are editing a rule, not one image.

Four sizes, one layout

The frame you tune is not tied to a single shape. The same set of numbers draws a portrait tile for the mobile grid, a landscape card for the desktop rail, a wide banner for the hero slot and a square for search. You design once; the studio produces every surface your front end asks for, with the focal point held in place at each one.

Promo without a design request

Seasonal takeovers, “NEW” badges and event frames are data, not artwork. Schedule them in the studio and they apply across the grid at once — a Drops & Wins frame on a hundred games is a toggle, not a hundred files. The lobby runs like a content calendar instead of a design backlog.

Then hand it to the lobby

What you build in the studio is the same art the API serves — so once a treatment is set, every size exports and every tile stays current automatically. The studio is where the decision is made; the renderer and the API carry it to every game and every surface, forever.

It is built for the team that actually runs the lobby: no Photoshop licence, no design ticket, no waiting. Pick, tune, publish.
